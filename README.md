# beautifulCards · 读书笔记卡片排版工具

一个纯前端、零依赖的卡片排版工具：批量输入读书笔记文本，一键生成风格统一、好看的复习卡片。支持多项目管理、多套模板、可视化自定义模板，并可导出 PNG / PDF。

🔗 在线使用（GitHub Pages）：<https://williamzlj.github.io/beautifulCards/>

## 功能特性

### 项目管理
- **首页卡片式项目管理**：新建、重命名、复制、删除、上移/下移排序
- **项目导入 / 导出**：单个 JSON 文件即可备份或迁移项目
- **只读查看模式**：进入项目后可切换为只读查看，隐藏所有编辑入口，只看不改
- 项目数据保存在浏览器 localStorage，无需注册、无需后端

### 卡片内容
- 批量输入文本，用 `---` 分隔多张卡片；`#` 开头为标题（可省略，无标题自动识别）
- 每张卡片自动带：**书名、作者、日期、备注（签名）**，且均可修改、可单卡覆盖
- 卡片内可双击或点 ✎ 按钮单独编辑标题、正文、备注
- 页码编号可开关；页码为右下角大号水印式设计

### 模板系统
- **9 套预设模板**：中国风、简约纸纹、现代极简、拼贴杂志、复古打字机、暗夜模式、水墨风、笔记本横线、渐变现代
- **可视化自定义模板编辑器**：拖拽添加文本 / 矩形 / 线条 / 圆形元素，自由调整位置、大小、颜色、字体、对齐，并绑定字段（书名/作者/日期/备注/标题/正文/序号）
- **自定义背景图片**：支持上传背景图作为卡片最底层
- 丰富的参数调节：标题/正文/书名/作者/日期/备注各自的字号、字体、颜色、对齐，卡片尺寸、内边距、行高等

### 导出
- 导出 PNG（整页网格 / 逐张 ZIP）
- 导出 PDF，每页可选 1 / 2 / 4 / 6 / 9 张卡片
- 网格 / 翻页两种预览模式，排版比例完全一致

## 快速开始

### 直接使用
用浏览器打开 `index.html` 即可（推荐 Chrome / Edge）。或直接访问 GitHub Pages 在线版本。

### 本地启动（推荐，避免字体等资源的 file:// 限制）

任意静态服务器均可，例如：

```bash
# Python
python -m http.server 8000

# Node（无第三方依赖）
npx serve .
```

然后访问 <http://127.0.0.1:8000>。

## 输入格式

```
# 第一章 论读书
读书使人充实，讨论使人机智，笔记使人准确。
---
# 第二章 论友谊
真正的友谊在于心与心的契合，而非利益的交换。
---
没有标题的卡片，直接写正文即可，这一段就是一张无标题卡片。
```

- `---`：卡片分隔符
- `# ` 开头：标题行（可省略）
- 其余内容：卡片正文

## 目录结构

```
beautifulCards/
├── index.html            # 项目管理首页（卡片式项目列表）
├── editor.html           # 编辑 / 只读查看页
├── css/
│   ├── style.css         # 全局样式 + 编辑器/首页样式
│   └── templates.css     # 9 套预设模板样式
└── js/
    ├── app.js            # 编辑器主逻辑（渲染、参数、事件）
    ├── projects.js       # 项目加载 / 只读模式 / 自动保存
    ├── storage.js        # localStorage 持久化（项目、模板、参数）
    ├── parser.js         # 文本解析为卡片数据
    ├── templates.js      # 预设模板配置
    ├── template-editor.js# 可视化拖拽模板编辑器
    └── exporter.js       # PNG / PDF 导出
```

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，**无构建步骤、无运行时依赖**
- 数据存储：浏览器 localStorage（项目、卡片、模板、参数均在本地）
- 中文字体通过 Google Fonts CDN 加载（霞鹜文楷、思源宋体/黑体、马善政毛笔、站酷系列等，均为免费商用字体）
- 导出使用 html2canvas / jsPDF / JSZip / FileSaver（CDN 引入）
